## 📖 项目愿景与使命

随着独居人群比例的大幅上升以及人际关系的模块化，“孤独猝死未被及时发现”和“猝然离世后身后事无法交代”正在成为无数人内心深处不可言说的焦虑。

**LifeVault（生命保险箱）** 是一款以 **“零知识证明与端到端加密”** 为基石的数字化生命守护与告别托付系统（Dead Man's Switch + Digital Legacy Vault）。

我们不碰封建迷信，不替代法律遗嘱，而是专注于解决两件事：
1. **生前安全守护**：用极简、非侵入式的方式感知用户的生存状态（低频签到与分级预警）。
2. **死后情感与交代托付**：在确信用户离世后，将生前写下的真心话、葬礼心愿（如专属BGM/仪式风格）、跨圈层好友联络名单，通过**双人双密码门限解密机制**，体面且准确地交付给指定亲友。

## 💎 核心唯一卖点（The Ultimate Selling Point）

> **“零知识架构（Zero-Knowledge）：你的秘密，连我们也看不见。”**

对于托付身后事和极度私密的遗愿产品，**“绝对安全”不是加分项，而是生死线**：
- **浏览器/客户端本地加密**：文本、视频、录音在离开用户手机/电脑前，就已经在本地完成高强度加密（AES-256-GCM）。
- **平台无明文存储**：数据库中存储的全部是杂乱无章的密文散列，哪怕服务器被黑客拖库、被内部人员导出，任何人看到的也只是一堆乱码。
- **双人双密码（门限秘密共享）**：密钥被切分为不可逆的两份或多份，只有身故后两位指定信使同时输入密码，明文才会被还原。这从物理和数学上杜绝了任何单方面窥探的可能。
